Proteger dados com senha

Ativa criptografia de verdade (AES-256) nos dados salvos neste aparelho e nos backups exportados. Sem a senha, ninguém consegue ler os dados — nem quem tiver acesso aos arquivos do navegador.

Guarde essa senha num lugar seguro — se esquecer, não tem como recuperar os dados salvos neste aparelho.

🔒 Proteção por senha ativa

Transferir dados entre aparelhos

Esta versão (instalada fora do Claude) guarda os dados só neste aparelho/navegador. Para levar os dados de um aparelho para o outro: exporte um arquivo aqui e importe-o no outro aparelho. Nada é enviado para nenhum servidor — o arquivo fica só com você.

Importar substitui todos os dados atuais deste aparelho pelos dados do arquivo escolhido. Confira se é o arquivo certo antes de confirmar.

Importar de planilha

Prefere preencher os dados numa planilha em vez de digitar aqui? Baixe o modelo, preencha no Excel e importe de volta. A importação substitui os dados atuais do aplicativo.

Exportar planilha

Baixe todos os seus dados atuais numa planilha. Serve como backup ou para levar seus dados para uma futura versão deste aplicativo.
