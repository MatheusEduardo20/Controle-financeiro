Contas fixas

Aluguel, prestação da casa, conta de celular — despesas de valor fixo que você paga todo mês. Cadastre uma vez e elas entram automaticamente no cálculo de todo mês, sem precisar lançar de novo.

Dica: segure uma conta por um instante e arraste para mudar a ordem.

Se o valor muda todo mês (água, luz...), coloque um valor estimado. Na hora de pagar você digita o valor real, e o app mostra a média dos meses anteriores como referência.

Se for no cartão, esse valor entra na sua fatura e no seu limite.

Sincronizar com a nuvem

Acesse os mesmos dados em qualquer aparelho (celular, computador...). Seus dados são embaralhados (criptografados) neste aparelho ANTES de subir para a nuvem, usando a senha da sua conta — nem o servidor consegue ler.

Guarde essa senha muito bem: ela também é a chave que embaralha seus dados. Se esquecer, não tem como recuperar os dados enviados à nuvem.

☁️ Conectado como

A sincronização com a nuvem não está disponível neste momento (sem conexão com o serviço). Seus dados continuam salvos neste aparelho normalmente.

Backup

Seus dados já ficam sincronizados na nuvem. Use o backup só como cópia de segurança: baixe um arquivo para o seu computador e guarde num lugar seguro. Se algo der errado um dia, é só importar esse arquivo de volta para recuperar tudo.

O backup guarda todas as informações do app: contas, lançamentos, metas, parceladas, contas fixas, empréstimos e cartões. Restaurar substitui todos os dados atuais pelos do arquivo escolhido; confira se é o arquivo certo antes de confirmar.
